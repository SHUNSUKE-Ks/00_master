# Opus 相談リスト

Sub_KanbanNote（Sonnet）で解決しきれない、または Opus に上げる基準（README.md「Opus へ上げる基準」）に当たる課題をためる場所。
利用者があとでまとめてメインチャットへ相談する。新しいものを上に足す。解決したら「状態」を書き換える（消さない）。

## 1件の書き方

```markdown
### <課題を1行で>
- 日時: 2026-09-27 14:05
- 状態: 未相談 / 相談中 / 解決（どこで・どう）
- 基準: <README の番号。例: 2（設計に関わる）>
- 症状・依頼: <何が起きているか／何を頼まれたか。スクショは中身を文字で>
- 試したこと: <やったことと結果。やっていなければ「なし」>
- 関係ファイル: <パス>
- いまの状態: <手をつけていない／安全な部分だけ直した（何を）>
- 急ぎ度: 高（使えない）／中（不便）／低（あとでよい）
```
