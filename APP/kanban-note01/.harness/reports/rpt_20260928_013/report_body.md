# 会話ログの音声（2026-09-28）

## 依頼
会話ログに対して音声を収録して、再生する機能。PWA でどこまでやれるか。

## できたこと（第1段階: この端末に保存）
- セリフの右の **マイク**: 押すと録音、もう一度押すと止めて保存。録音中は赤い点が声の大きさで動き、時間が出る。録り直しは確認してから。
- **スピーカー**: 金色＝録音あり。押すと再生／停止。0.6秒長押しで録音を消す。
- 見出しの **「音声 n/m」** と **「▶ 通して再生」**: 録音のあるセリフを上から順に鳴らし、鳴っている行を選んで見せる。「■ 止める」で止まる。
- セリフを書き直すと、録音は新しい文字に付いていく（黄色の点＝録音のあとでセリフが変わった）。登場人物の名前を変えても外れない。
- 別の端末やタブで本文が変わって合わなくなった録音は「合わない音声」に残り、選んでいるセリフに付け直せる。
- 録音はこの端末の IndexedDB。ブラウザに「消さないで」と頼む（断られても残るが、端末の容量が足りないと消されることがある）。

## PWA でどこまでやれるか
| できる | メモ |
|---|---|
| マイクで録音・再生 | HTTPS（本番は Vercel なので可）とマイクの許可が要る。Android Chrome は webm/opus、iPhone は mp4 |
| エコー・雑音の抑え、音量の自動調整 | ブラウザの機能。録音室の品質ではない |
| 声の大きさの表示・波形 | Web Audio |
| 端末に保存（数百MB） | IndexedDB。容量は端末の空きしだい |
| 端末間で共有 | Firebase Storage に上げれば可（ギャラリーと同じ仕組み）。ルールの確認が要る |
| 簡単な編集 | 前後の無音を切る・音量をそろえる・WAV に書き出す（Web Audio で可能） |
| まとめて書き出し | ページの録音を ZIP／1本の WAV にしてダウンロード |
| 再生速度・ここから再生・ループ | 可 |
| 合成音声で代読 | speechSynthesis（端末の声。未収録のセリフの仮置きに） |
| 文字起こし | Chrome の音声認識（オンラインが要ることが多い） |

| むずかしい・できない | 理由 |
|---|---|
| 画面を消した後・別のアプリに移った後も録り続ける | PWA は裏に回ると止まる |
| 本格的な編集（多重録音・エフェクト） | 作れなくはないが大仕事。DAW（AviUtl2 など）へ書き出す方が早い |
| iPhone の PWA | 録音はできるが、制限や不具合が多め |

## 確かめたこと
- 型チェック・本番ビルド成功。マイクを止めるヘッダーが無いことを確認。
- jsdom 16本すべて PASS（計464件）。新しい音声のテスト 28件（マイク・録音・再生はテスト用のまね）。
- 開発サーバーで会話ログの見た目を確認。タブレット幅で見出しが縦に折れていたのを直した。
- **実機のマイクでの録音はまだ**。デプロイ後に Android の PWA と PC で確かめる必要がある。
