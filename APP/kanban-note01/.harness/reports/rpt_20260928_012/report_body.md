# Sceneスロットと下書きの9グリッド・発注リスト（2026-09-28）

## 依頼
- ギャラリーから、各作品（Title）の Sceneスロットに登録したい。
- 下書きの Scene サイドバーに、今と違う見え方「9グリッド」を足す。サイドバーの幅で9マス（Scene 名＋サムネ）。押すと Scene 名がタグになって本文に書かれる。
- テンキー 1〜9 がその9マス。− ＋ でパレットごと替える。0 は画像の無いラベルだけのタグを置き、絵の発注リストに 名前・作品・納品先 を書く。
- 将来は発注用のプロンプト辞書。まず CODEX に画像を頼むとき、担当 agent とカメラアングル（あおり・下から など）を共有する必要がある。

## できたこと
### Sceneスロット（作品ごと）
- 作品に `sceneSlots` を持つ。並び順がそのままパレット（9つで1枚）とマスの番号。
- 1つのスロット = Scene の名前 ＋ 写真（ギャラリーの写真 id）。写真が無ければ **絵の発注**。
- 作品と一緒にクラウドへ保存されるので、どの端末でも同じパレットになる。

### 執筆デスクの Scene サイドバー（PC の右パネル／スマホのサイドバー）
- 上に「一覧／9グリッド」。見え方は端末ごとに覚える。
- 9グリッド: 3×3 のマスに サムネ・Scene 名・番号。写真の無いマスは「絵待ち」。
- マスを押す／テンキー 1〜9 → カーソルの位置に `[Scene_"名前"]`。
- テンキー − ＋ → パレットを前・次へ。
- テンキー 0 → ダイアログで Scene の名前（選んだ文字や柱の場所が最初に入る）と、どんな絵かを聞く → 本文に `[Scene_"名前"]` を置き、発注リストに載せる。
- テンキーは **9グリッドが見えている間だけ** 使う。閉じていれば、テンキーでふつうに数字を打てる（上の段の数字は変わらない）。

### ギャラリー
- 写真の情報に「Sceneスロット」: 作品を選び「新しいスロット」に名前を付けて登録、または「発注『…』へ納品」を選ぶ。登録した所（作品・パレット・番号）が並び、× で外せる（発注から来た物は発注に戻る）。
- 左に「発注リスト（絵待ち）」: 名前・作品・納品先（例: 作品名／Sceneスロット パレット1・2番）・依頼日・どんな絵か・カメラ・担当。
  - 「写真を入れて納品」: その場で写真を選ぶと、ギャラリーに入れてスロットに納品する。
  - 「発注リストを JSON でコピー」: 画像を作る担当へ渡す形（`note_story.image_order.v0.1`）。
  - 「発注をやめる」（本文のタグは残る）。

## PWA でテンキーは使えるか
使えます。キーの信号でテンキーの 1 と上の段の 1 を見分けられるので、PWA（インストールしたアプリ）でもブラウザでも同じように動きます。Android に Bluetooth のテンキーをつないだ場合も、キーを送ってくれれば同じです（届くキーは「キー入力モニター」で確かめられます）。

## CC への申し送り: CODEX に画像を頼むとき共有すること
発注リストの JSON に、次の欄を用意しました（中身はこれから決める）。

| 欄 | いま | これから |
|---|---|---|
| `agent` | 既定 `codex`（発注リストで書き換えられる） | 担当ごとの頼み方（CODEX・3D 担当など）とつなぐ |
| `camera` | 仮の候補: 正面／あおり（下から）／俯瞰（上から）／真横／背面／アップ／引き（全景） | プロンプト辞書の「カメラ」の項にし、CODEX への英語の指示に変換する |
| `note` | どんな絵か（自由に書く） | 時間帯・天気・人物の有無・画風などを辞書の項目に分ける |
| `deliverTo` | 作品名／Sceneスロット パレット・番号 | 納品のしかた（ファイル名の決まり・置き場所）を決める |

決めること（案）: ①プロンプト辞書の項目（カメラ・構図・時間帯・画風）、②CODEX へ渡す文の形（JSON → 英語の指示）、③納品のファイル名と、納品したらスロットに入る流れ（いまは手で「写真を入れて納品」）。
