# 登場人物を9つの枠に・名前スペースで一元管理

## 依頼
- Character1〜9 を初期の文字列で保存、Alt+番号でそのキャラクターを作れるように
- 名前スペースで名前を書く・変えると、作品の CHARACTER と部品が書き換わる。名前は DB で一元管理
- 質問: その場限りの NPC は別のブロックの種類にするか

## 対応
- 作品ごとに9つの枠（初期 Character1〜9）を DB に保存。Alt+1〜9 は常に有効
- 名前札のメニュー先頭に名前スペース。変えると作品の登場人物・全セリフ・サイドバー・作品ページが変わる
- 作品ページの名前の欄もセリフまで付け替えるように（以前は登録だけ）
- NPC: ブロックの種類は分けず、場面の人物欄で持つのがおすすめ（未実装）

## 検証
- tsc・vite build 成功、jsdom 9本 PASS、開発サーバーで名前札のメニューを確認
- デプロイはしていない
