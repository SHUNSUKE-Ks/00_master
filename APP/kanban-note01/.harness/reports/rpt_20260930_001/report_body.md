# V2.1 導線の見直し（ヘッダーのメモ・ホーム・Titleなしの人物・記号キー）

## 変えたこと
1. **ヘッダー「メモ」**: 一覧を挟まず、Title なしの下書き画面へ直接入る。何も書いていない最新のメモがあれば再利用、無ければ新規。一覧は画面左上「← アイディアメモ」から。
2. **メニューの「ホーム」を削除**: 左上のロゴ「Note Story」が既にホームへ戻るボタン。
3. **Title なしの人物**: 先頭の9枠を CharacterA〜I（初期値）にした。Alt+1〜9 はこの枠を呼ぶ。作品の人物は、その下に番号なしで並ぶ（人物欄から押して貼る）。
4. **記号キー（下書き中の NAV 右下）を大きく**: 22×30 → 33×44、文字 12.5 → 17px。NAV の幅は執筆デスクだけ 76px。

## 確認していないこと
- 画面での動作確認（開発サーバーは自動起動しない規則）。型チェックのみ通過。
- 記号キーの高さ：6キー×3行＋NAVボタンが、縦の短い画面（高さ760px以下）に収まるか。収まらなければ2列のまま高さだけ詰める。
