# 執筆デスクの記号キーと本番デプロイ（2026-09-28）

## 依頼
下書きの NAV の右下に 半角の # {} [] () : を置き、押すと文字を打つ。# は章や小見出しに使う。文中のメモや補足にはどの括弧が正解か、// も足すべきか。実装したらデプロイ。

## できたこと
- NAV の右下（スマホ・タブレットは右隣の NAV の一覧の下、PC は右の NAV の下端）に 2列×3段の記号キー。
- `#`: 行の頭に見出しの印。押すたびに `##` `###`。
- `{}` `[]` `()`: 選んだ文字を囲む。選んでいなければ間にカーソル。
- `:`: 半角コロン。
- `//`: 行のメモの始まり（行の途中なら前に空白）。
- 押しても本文のカーソルは外れない。

## 括弧の使い分け（提案）
| 記号 | 使いどころ | 書き出すとき |
|---|---|---|
| `[ ]` | タグ（`[Scene_"…"]` `[bg_town_night]`）専用 | 機械が読む |
| `{ }` | 文中の書き手のメモ（あとで直す・調べる） | 本文に出さない |
| `//` | 行のメモ（ここから行の終わりまで） | 本文に出さない |
| `( )` | 本文に出る補足 | そのまま出す |
| `備考：` | 何行にもわたるメモ | 本文に出さない（今までどおり） |

## 確かめたこと
- 型チェック・本番ビルド成功。jsdom 16本すべて PASS（計481件）。
- 開発サーバーのスマホ幅で、NAV に収まることを確認（最初は縦に収まらず、2列にした）。
