# 下書きボタン・アイディアメモ・執筆デスク

## 依頼

- タイトル一覧の各タイトルに「下書き」ボタン。すぐ書き始められるように
- 下書き・メモに作成日時・更新日時を持たせる（画面には出さない）
- 「新しいタイトル」の隣に「新しいメモ」（どのタイトルにも属さないメモ）
- これらに会話ログのNAVと、共通tagの入力候補
- どこにも属さないメモを Google Keep 風（成分表の GalleryCard 式）で並べるページ
- 作ってから10日のうちに進捗を更新しなければ、ごみ箱へ（完全には消さない）
- 終わったらデプロイ
- 質問: 無変換＝左パネル、変換＝右パネル、無変換＋Q で候補を貼る、はできるか（画面には反映しなくてよい）

## やったこと

| 場所 | 内容 |
| --- | --- |
| タイトル一覧 | 各カードに「✎ 下書き」と下書きの数。「＋ 新しいタイトル」「＋ 新しいメモ」 |
| 執筆デスク（新） | 1枚のテキスト。左NAV＝一覧・人物・Scene、右NAV＝WW・演出（共通tag）。スマホはオーバーレイ |
| 候補のHooks | `sideNav.tsx` の表1つを会話ログと執筆デスクで共有。柱の行→柱の候補、備考の行→共通tag |
| アイディアメモ（新） | メニュー「メモ」。Keep 風の段組み、成分表のカードの形（名前→金の小見出し→本文→タグ）、進捗の札、検索、ごみ箱 |
| ごみ箱 | 10日のうちに進捗を一度も変えないメモだけ。消さずに印をつける。戻すと、また10日 |

作品の下書きには10日のきまりを当てていない（依頼の対象が「何にも属していないメモ」だったため）。

## 質問への回答（要点）

- ブラウザでは無変換＝`NonConvert`、変換＝`Convert` として取れる。修飾キーではないので「押している間」をページ側で覚えれば、無変換＋Q を作れる
- 日本語入力の変換中は IME が先に取る。変換キーのほうが再変換とぶつかりやすい
- KeyDeck の送れるキーに無変換・変換は無い（F13〜F24 はある）。辞書に足すか、F13〜F24 で受ける
- 専用キーボードにする本当の山は、「いま Q に何が入っているか」を KeyDeck のボタンに出すこと（ページ → Hub へ候補の並びを送る道が要る）
