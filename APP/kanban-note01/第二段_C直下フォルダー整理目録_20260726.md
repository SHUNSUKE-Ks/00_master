## 2. 個別判断

### MagicMic

「一度消したはずなのに残っている」可能性はある。`FeatureFile` と `x86` が残っているため、フォルダーを直接消す前に以下を確認する。

1. Windowsの「インストールされているアプリ」にMagicMicが残っていないか確認。
2. タスクマネージャーでMagicMic、音声デバイス、仮想マイク関連プロセスを確認。
3. アンインストーラーがある場合はそれを使用。
4. アプリ一覧に無く、現在使っていないことを確認した後、フォルダーを保留倉庫へ移すか削除する。

結論: 残骸の可能性はあるが、今回は直接削除しない。

### Log

確認できた最終記録日は2025-05-28。ログの内容は次のようなもので、OSの中核ログではない。

```text
GetGCExtensionState Extension ID ... state is ...
CanOfferExtnInMF Extension ID is bingwallpaperdse@microsoft.com ...
```

Chrome系またはMicrosoft系のブラウザー／拡張機能に関係する記録の可能性があるが、`FRE` の正式な作成元まではこの3ファイルだけでは断定できない。1年以上更新がないため、必要なら `E:\` の保留倉庫へ移して3か月後に再確認する。

### LDPlayer

Androidエミュレーターを今後使わないなら、フォルダー削除ではなく「インストールされているアプリ」からLDPlayerをアンインストールする。その後、残った空フォルダーだけを整理する。現在もAndroidゲームや検証で使うなら保持。

### Intel / DRIVER

`C:\Intel` はグラフィックス関連の展開物、`C:\DRIVER` は複数デバイス用ドライバーの保管物とみられる。これらは古くても、再セットアップ時に役立つ可能性がある。少なくとも `DRIVER` はEドライブへバックアップしてから判断する。

### inetpub

IISを使っていない場合でも、先にIIS機能の状態を確認する。IISが有効ならフォルダーを削除しない。IISを無効化済みで、ローカルWebサーバーとしても使っていない場合に限り、残骸を整理候補とする。

### GameFile

中身はバンダイナムコのネットワークランチャーのインストーラー一件。現在バンダイナムコのゲームを使っていないなら不要の可能性が高い。ただしゲームの再インストールに使う可能性があるため、削除前にEドライブへ退避するか、再取得可能なインストーラーか確認する。

### Cakewalk Projects / Cakewalk Content

これは「使っていないアプリの残骸」ではなく、ユーザー制作物と音源素材。プロジェクトには音楽・ゲームBGMの資産が含まれる可能性があるため、削除しない。Cakewalkを今後使わない場合は、プロジェクトとContentを対にしてEドライブのDTMアーカイブへ移す候補。

### adobeTemp

Adobe製品を一切使っていないことが確認でき、Adobeのアンインストール・更新処理も動いていない場合は削除候補。ただしフォルダーそのものではなく、中身と作成日時を確認してから処理する。

## 4. 推奨する整理順

1. `MagicMic`、`LDPlayer`、`adobeTemp` は使用状況とアンインストール状態を確認。
2. `Log` は内容を記録後、Eドライブへ短期保留または廃棄。
3. `GameFile` はバンダイナムコ製品の利用予定を確認。
4. `DRIVER` はEドライブへバックアップしてから本体を判断。
5. `Cakewalk Projects` と `Cakewalk Content` は対でアーカイブ。
6. 最近のワークスペースは、現行作業を止めずに「企画」「原本」「ビルド成果物」「一時ファイル」を分ける。

## 5. 安全確認用コマンド

アプリのアンインストール後に残骸を確認するための読み取り用コマンド。

```powershell
Get-ChildItem 'C:\MagicMic','C:\LDPlayer','C:\adobeTemp' -Force -ErrorAction SilentlyContinue
```

IISの状態確認用。

```powershell
Get-WindowsOptionalFeature -Online -FeatureName IIS-WebServerRole
```

この記録の作成時点では、削除コマンドは実行していない。
