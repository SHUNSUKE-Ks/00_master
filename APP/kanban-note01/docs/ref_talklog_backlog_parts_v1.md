## 図3: 目標の見た目（ゲームのバックログ画面）

| 部品 | 中身 |
|---|---|
| 背景 | ゲーム画面を暗く沈めた上に重ねる（周辺減光）。文字は白 |
| 名前札 | 左寄せの話者名。細い明朝体。**下に細い装飾線**（左端に小さな飾り、右へ伸びて途切れる） |
| 本文 | 名前札より一段右に字下げ。1〜2行。明朝体・字間やや広め |
| 右の操作 | 各発言の右端に四角い暗色ボタンが2つ: **スピーカー（音声再生）**・戻る（↶）。→ **戻るは削除し、マイク（録音）に置き換える**（利用者指示） |
| 区切り | 発言と発言の間に、端が消える細い横線 |
| 画面右端 | 縦のスクロールバー、別ボタン群（早送り・全画面・ログ・設定）、下部に音量スライダー（75%） |
| 将来 | 名前札の左にキャラアイコンを置く（**今は名前と文字だけ**） |

## 作るVIEWでの対応

- 名前札＋装飾線＋字下げ本文＋端の消える区切り線 → そのまま採用（明朝体・暗い舞台）
- 右の2ボタン → 🔊スピーカー（予定）＋🎙マイク（予定）。今は押すと「予定」と出るだけ
- 画面右端の早送り等・音量 → 読むゲーム画面の部品なので採用しない（書くための画面のため）
- 書式・保存先は図2と同じ（`名前：「本文」`、`page.body` または `scenarioLogs`）。**VIEWを変えるだけでデータは共通**
