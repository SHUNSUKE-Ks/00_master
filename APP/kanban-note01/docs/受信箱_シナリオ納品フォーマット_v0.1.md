# 受信箱: シナリオ納品フォーマット v0.1（Note Story / kanban-note01）

- 作成: 2026-09-28（メインチャット・Opus）
- 目的: 外（CC＝CreatorCompass で働く人・AI、別の制作チャット）から、シナリオ（場面と会話）を Note Story に足すときの入口と形
- アプリでの見え方: タイトル画面の見出しの下「**最新の変更ログ**」に「外から」として出る → 「取り込む」で反映 → 「開く」
- 実装: `src/v21/inbox.ts`（読み込み・形のチェック・取り込み）、`src/v21/ChangeLogPanel.tsx`（表示）

## 1. 置き場と流れ

```
C:\00_master\APP\kanban-note01\public\inbox\
  index.json               ← 一覧（items に1件足す。新しい物を上に）
  <packageId>.json         ← 中身（1納品＝1ファイル）
```

1. 送る側が `<packageId>.json` を置き、`index.json` の `items` に1件足す
2. 本番に出す（`npx --yes vercel --prod --yes`。デプロイは利用者の指示のときだけ）
3. 利用者がアプリで「最新の変更ログ」→「取り込む」
4. 取り込んだ物は、同じ packageId では二度取り込まれない（ノートの `inboxIds` に記録）

**送る側は Firestore（クラウドの本体）に直接書かない。** 必ず受信箱を通し、取り込むかどうかは利用者が決める。

## 2. index.json

```json
{
  "format": "note_story_inbox",
  "version": "0.1",
  "items": [
    {
      "packageId": "scn_20260930_gate_night",
      "title": "村の門の夜（新しいイベント）",
      "summary": "門番とミアの会話 2場面",
      "path": "/inbox/scn_20260930_gate_night.json",
      "receivedAt": "2026-09-30T10:00:00+09:00",
      "from": "CC"
    }
  ]
}
```

| 項目 | 必須 | 中身 |
|---|---|---|
| packageId | ○ | 一意の ID。`scn_<日付>_<英小文字と_>` を推奨。ファイル名と同じにする |
| title | ○ | 変更ログに出る名前 |
| summary |  | ひとこと（何場面・誰の会話か） |
| path | ○ | `/inbox/<packageId>.json` |
| receivedAt | ○ | 置いた日時（ISO 8601、+09:00）。変更ログの並び順に使う |
| from |  | 送り手（例: `CC`） |

## 3. 中身（note_story_scenario v0.1）

### 3-1. 新しいイベントを作る（mode: newEvent）
```json
{
  "meta": { "format": "note_story_scenario", "version": "0.1", "packageId": "scn_20260930_gate_night", "title": "村の門の夜", "from": "CC", "createdAt": "2026-09-30T10:00:00+09:00" },
  "mode": "newEvent",
  "target": { "title": "はじまりの町の防衛線" },
  "event": { "title": "村の門の夜", "synopsis": "夜の門番に、ミアが村の外の様子を聞く", "characters": ["ミア", "門番"] },
  "cast": [ { "name": "門番", "role": "村の門を守る兵士" } ],
  "scenes": [
    { "title": "門の前", "body": "柱：村の門・夜\n\n門番：「止まれ。こんな時間にどこへ行く」\n\nミア：「森の様子を見たいの」" },
    { "title": "見張り台", "body": "柱：見張り台\n\n門番：「……灯りが三つ、動いている」" }
  ]
}
```
- `target.title` の Title（名前が完全に一致する物）の下にイベントを作る。Title タグが付く
- 登場人物: `event.characters` の順に、そのあと `cast` にだけいる人を、イベントの9つの枠に上から入れる（枠の番号＝Alt+番号）。Title の登場人物と同じ名前の人には Character タグが付く

### 3-2. 場面を足す（mode: appendScenes）
```json
{
  "meta": { "format": "note_story_scenario", "version": "0.1", "packageId": "scn_20261001_gate_night_add", "title": "村の門の夜（続き）", "from": "CC" },
  "mode": "appendScenes",
  "target": { "title": "はじまりの町の防衛線", "event": "村の門の夜" },
  "cast": [ { "name": "旅の商人", "role": "門の外で足止めされた商人" } ],
  "scenes": [ { "title": "明け方", "body": "柱：村の門・明け方\n\n旅の商人：「やっと開いたか」" } ]
}
```
- `target.event` があれば、その Title のそのイベントに、無ければ Title そのものに、場面を後ろへ足す
- 新しい話者は空いている枠（Character1〜9）に入る。今いる人の名前は変えない

### 3-3. 本文（body）の書き方
Note Story の会話ログと同じ書式。ブロックの間は空行1つ。
```
柱：場所・時間
名前：「セリフ」
備考：メモ（本文に出ない）
```
- ナレーション（地の文）は `ナレーション：「…」`
- タグは `[Scene_"名前"]` `[bg_town_night]` のように `[]` で囲む（`{}` と `//` は書き手のメモ）

## 4. 取り込めないとき（アプリに理由が出る）
| 理由 | 直し方 |
|---|---|
| 形式が違います | `meta.format` を `note_story_scenario` に |
| Title「…」が見つかりません | `target.title` をアプリの Title 名と完全に同じに |
| イベント「…」が見つかりません | `target.event` を、その Title に付いたイベント名と同じに |
| scenes が空です | 場面を1つ以上 |

## 5. 素材（画像）を送るとき
画像つきの作品は、今までどおり **納品パッケージ**（`public/deliveries/`、形式 `note_story_delivery v0.1`、`src/v21/deliveries.ts`）で送る。
`images[].kind` は `character`（立ち絵）／`enemy`（エネミー）／`background`（背景）／`item`（小物）。**エネミーは `enemy`**（2026-09-28 追加。Title ページの Assets のタブで分かれる）。
