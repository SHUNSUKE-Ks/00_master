## 質問への回答（2026-09-26）: 無変換＝左パネル・変換＝右パネル、無変換＋Q で候補を貼る

できる（ブラウザで取れる）。ただし次の条件つき。

- Windows の Chrome／Edge では、無変換は `key: "NonConvert"`、変換は `key: "Convert"` としてページに届く。Ctrl や Alt のような修飾キーではないので、「押している間」をページ側で覚えて、その間に押された Q などを組み合わせとして扱う
- 押して離しただけ（他のキーを押していない）＝パネルの開閉、押したまま Q ＝候補を貼る、と分けられる
- 注意: 日本語入力が変換中のあいだは、キーは IME が先に受け取る（ページには `Process` としか届かない）。無変換は変換中ならカタカナへの変換、変換は再変換にも使われるので、**変換キーのほうが IME とぶつかりやすい**。確定したあと（変換中でないとき）なら両方届く
- 候補の頭の文字は、左手で押しやすい Q W E R T／A S D F G／Z X C V B の15個を、いま開いている候補の上から順に当てる案（会話中に地名や名前を呼ぶときに使う）

KeyDeck で専用キーボードにする場合:
- いまの KeyDeck が送れるキー（`APP_KeyDeck01/crates/proto-keymap` の `VK_DICTIONARY`）には、無変換・変換が**入っていない**。F13〜F24 は入っている
- 道は2つ: (a) 辞書に NONCONVERT（0x1D）・CONVERT（0x1C）を足す（辞書が「正はここ1箇所」なので小さな変更で済む） (b) ページ側で F13〜F24 の組み合わせも受け付け、KeyDeck からはそちらを送る（IME とぶつからない）
- 押したままの組み合わせを KeyDeck がどう送るか（修飾キー以外を押したままにできるか）は未確認
- 本当の山は、**Q に何が入っているかを KeyDeck のボタンに出す**こと。候補は行の種類（Hooks）で変わるので、ページ → Hub へ「いまの候補の並び」を送る道が要る（いまの KeyDeck の取り込みは手で行うファイル形式 `keydeck.deck_import.v1` だけ）
