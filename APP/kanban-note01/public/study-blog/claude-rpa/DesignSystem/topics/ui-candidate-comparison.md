# ui-candidate-comparison: UI候補比較

## 比較表

| 技術 | 概念 | 特徴 | 評価 |
|---|---|---|---|
| Ark UI | 状態駆動UI | ZagJSベース / Headless / 多Framework対応 | ◎◎ |
| Kobalte | 機能集 | Solid専用 / 安定 / Radix UI系 | ◎ |
| Corvu | 軽量UI | 新興 / Kobalte代替候補 / 軽量 | ○ |
| Hope UI | 完成品UI | Chakra風 / すぐ使える / 改造性は低め | △ |
| SolidUI | 雛形集 | shadcn/ui系 / コピペ前提 / AIと相性良い | ○ |
| Park UI | Ark UI完成版 | ZagJS -> Ark UI -> Park UI | ○ |
| Chakra UI | React中心 | 情報量は多いがSolidJS主軸ではない | △ |
