# NovelEngine / Study 目次

自分用NovelEngineを、納品物、画面状態、JSON変換、DevStudioの4つに分けて読む。

## 読む順番

| 順 | Card | 目的 |
| --- | --- | --- |
| 1 | NovelEngine 納品スキーマ | 外部AgentやNoteから何を渡せばよいかを固定する |
| 2 | gameStore：screen/phaseで進行を駆動する | Novel画面の現在地をStateとして理解する |
| 3 | App.jsx：modeで画面を切り替える | SolidJSの画面分岐を読む |
| 4 | scenarioOneShot：下書きをruntime JSONへ変換する | Noteの会話ログをEngine用JSONへ寄せる |
| 5 | DevStudio：SchemaとCopy導線 | schema、tag、copy UIを制作画面に載せる |

## 要素分解

| Key | 意味 |
| --- | --- |
| 納品 | 外部からNovelEngineへ渡す完成候補データ |
| 状態 | 画面や会話位置を表す現在値 |
| 派生 | Stateから計算して表示に渡す値 |
| 遷移 | Screen、Scene、Talkを移動する処理 |
| 変換 | 書きやすい下書きをruntime形式へ寄せる処理 |
| 検査 | schemaやissueで受入可能か確認する処理 |
