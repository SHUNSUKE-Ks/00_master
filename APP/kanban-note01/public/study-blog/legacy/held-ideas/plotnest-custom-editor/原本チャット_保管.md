### Dashboard

目的は作品一覧、最近編集、進行状況。PCでは左に作品リスト、中央に選択作品概要、右に最近編集Card。Androidでは上に作品セレクタ、下に最近編集の縦リスト。

### InBox（最重要）

断片アイディアの放り込み場。表示はList / Kanban / Gallery。PCでは上部Filter、左タグfilter、中央Card一覧、右詳細preview。Androidでは検索+filter、Card縦scroll、FAB追加。

挙動は、@コメント抽出、#tag filter、Character/Location relation絞込、ドラッグでKanban移動。

### EventEditor（DSL入力）

SceneやEventを書く場所。PCは左DSL text area、右リアルタイム構造preview、下Relation link欄。Androidは上editor、下preview切替。

挙動は構文highlight、@コメント一覧jump、#tag自動補完、Character参照自動link。

## DBとRelation

### CharacterDB

List、ステッパー（CharacterArc）。PCは左キャラ一覧、中央詳細、右関連Event timeline。Androidは上基本情報、下Arc slider。

### LocationDB

Characterと同構造。初登場Eventと時間帯tagを追加する。

### Camera / PromptDB

構図・カメラワーク蓄積。Gallery表示を推奨。Cardは構図名、keyword、生成用prompt。Sceneから直接attach、ComfyUI出力用JSON生成。

### RelationView

将来拡張。PCではNode canvas、線はEvent ↔ Character ↔ Location。Androidでは簡易list表示。

## 出力と設定

### ExportCenter

JSON出力、API endpoint生成、素材発注仕様書生成。出力種別はRuntime JSON、Relation JSON、Prompt JSON、AssetSpec JSON。

### Settings

レイアウト設定: Compact Mode、Editor split比率、Galleryサイズ、Node表示ON/OFF。PC/Android別保存。

CustomKeyConfig: PCは Ctrl+Enter保存、Alt+QでQ構文挿入、Alt+@でコメント、Alt+#でtag、F2でRelation link。Androidは長押しmenu、custom toolbar、swipeでView切替。

## Zustand Store具体コード

```ts
import { create } from "zustand"

export type Event = {
  id: string
  title: string
  text: string
  tags: string[]
  characterIds: string[]
  locationIds: string[]
  nextEventIds: string[]
}

export type Character = {
  id: string
  name: string
  tagIds: string[]
  eventIds: string[]
}

export type Location = {
  id: string
  name: string
  eventIds: string[]
}

type AppState = {
  events: Record<string, Event>
  characters: Record<string, Character>
  locations: Record<string, Location>
  addEvent: (event: Event) => void
  updateEvent: (event: Event) => void
  deleteEvent: (id: string) => void
  addCharacter: (char: Character) => void
  updateCharacter: (char: Character) => void
  addLocation: (loc: Location) => void
}

export const useAppStore = create<AppState>((set) => ({
  events: {},
  characters: {},
  locations: {},
  addEvent: (event) => set((state) => ({ events: { ...state.events, [event.id]: event } })),
  updateEvent: (event) => set((state) => ({ events: { ...state.events, [event.id]: event } })),
  deleteEvent: (id) => set((state) => {
    const copy = { ...state.events }
    delete copy[id]
    return { events: copy }
  }),
  addCharacter: (char) => set((state) => ({ characters: { ...state.characters, [char.id]: char } })),
  updateCharacter: (char) => set((state) => ({ characters: { ...state.characters, [char.id]: char } })),
  addLocation: (loc) => set((state) => ({ locations: { ...state.locations, [loc.id]: loc } })),
}))
```

Relation自動更新はv0.2でservice分離推奨とされていた。
