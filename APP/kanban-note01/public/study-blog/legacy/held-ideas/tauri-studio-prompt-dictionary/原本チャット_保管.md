## Tauri開発メモ

### 方針

- デスクトップアプリ基盤: Tauri
- UI: React + Material UI（またはSolidJS）
- Backend: Rust（必要な部分のみ）
- Node.js: 開発ツール・Expressなど必要時のみ
- 将来ブラウザ版へ移植しやすい構成を意識する

### 素材管理ツール

画像、音声、BGM、Live2D、3Dモデル、JSON保存、tag検索、folder管理。

### マップエディタ（スタンプ配置）

背景画像の上へキャラ、item、家具、effectなどをスタンプのように配置する。

```json
{
  "image": "tree01",
  "x": 520,
  "y": 340,
  "scale": 1.2,
  "rotation": 0
}
```

将来候補はdrag移動、copy、delete、layer、undo、grid表示。

### ChatGPTキャラクター

Tauri内でLive2Dキャラ、chat UI、AI会話を実現する。将来は感情、motion、読み上げ、表情変更。

### MIDI楽譜制作

MIDI keyboard入力 -> note番号取得 -> 楽譜へ変換 -> MIDI保存 -> project保存。

将来はBPM、quantize、velocity、piano roll、五線譜。

### MIDIショートカット

例: C4は保存、D4は新規、E4は再生。アプリ専用shortcutとして使う。

### DJコントローラー対応

note、CC、回転、fader、knob、sliderをゲーム制作ツールの入力deviceとして利用。

### ExpressによるリモートUI

```text
PC -> Express Server -> 同一Wi-Fi -> iPad / Android / Browser
```

用途は左手device、remote、button panel、sub screen、debug UI。

### Material UI採用

Button、Dialog、Drawer、Tabs、TreeView、Card、Table、DataGridをゲーム制作ツール向けの業務UIに使う候補。
