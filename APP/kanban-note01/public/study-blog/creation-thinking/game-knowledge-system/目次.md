# 攻略本化 / Game Knowledge System

> 位置づけ: 現行の制作思考。旧資料のState駆動草稿とは別の棚で管理する。

## 核心

攻略本は最終成果物ではない。

**攻略本データを、ゲーム本体・タイトル別HP・図鑑・アセット管理へ再利用する。**

```text
世界情報 / MasterData
  -> 攻略本
  -> ゲーム本体
  -> タイトル別HP
  -> 図鑑 / Asset Browser
```

## 用語

| Key | 意味 |
| --- | --- |
| 情報中心設計 | ゲーム本体を先に固定せず、世界情報を正本として複数の表示先へ使う考え方 |
| 攻略本化 | 攻略本を、表示だけでなくゲーム情報を扱うUI部品とデータ構造として設計すること |
| 世界情報OS | Playable Game、Wiki、設定資料、Asset Browserを一体として扱う最終像 |
| MasterData | キャラクター、世界、敵、スキル、アイテム、シナリオなどの共通データ |
