## 2. 項目別の確認結果

### DEV-001: `C:\MyTools`

実体は「外部アプリ・開発用ショートカット・開発プロジェクト」が混在する作業置き場。

- `Docker Desktop Installer.exe`: インストーラー。常用アプリ本体ではないため、必要性を確認して保管または倉庫化。
- `GitHub Desktop.lnk`: GitHub Desktopへのショートカット。
- `Stream Deck.lnk`: Stream Deckへのショートカット。
- `PythonTools`: 継続利用するPythonツール群。
- `RustProjects01`: Rustの開発プロジェクト群。

推奨する将来構成:

```text
C:\MyTools\Installers
C:\MyTools\Shortcuts
C:\Dev\Python
C:\Dev\Rust
```

### DEV-002: `C:\MyTools\RustProjects01`

確認できた構成から、次の2系統が中心。

1. `CLI\novel-cli`
   - Rust製のノベルゲーム制作専用CLI。
   - `novel new`、`novel scene add`、`novel list` などを提供。
   - `target\release\novel.exe` と `target\debug\novel.exe` が存在。
   - 外付けキーボード、USB、Bluetooth、HID用アプリではない。

2. `CLI\command-nest`
   - Tauri、Solid、TypeScriptを使ったデスクトップアプリ。
   - `src-tauri\Cargo.toml` があり、RustはTauriのバックエンド部分。
   - 画面にはコマンド入力、ターミナル出力、辞書画面などの部品がある。

`Experiments`、`Server`、`Sync`、`Tauri`、`test` は今回の目録では「RustProjects01内の追加開発領域」として保留し、必要なら第二弾で個別調査する。

### DEV-003: `game_ui_installer`

今後も使うアプリ。ゲームUIの参考資料を収集するためのPythonツールで、保存結果も同じフォルダー内にまとめる設計。現状は `Voice of Cards The Isle Dragon Roars` の収集フォルダーと `Game UI Database` が確認できる。

### DEV-004: `C:\mydrive2026`

### DEV-005: `AppLayoutHtml`

Mytube本体を探すための検索対象ではあるが、確認できたのはサンプルHTML 2点。

- A案: `mytube_sample_a.html` — YouTube Dark型。赤いロゴ、検索中心、情報量の多い標準動画サイト型。
- B案: `mytube_sample_b.html` — Simple/Minimal型。暗色ベースに紫系アクセントを使う簡素なUI。

保存判断: A・Bとも削除せず、企画段階の模範資料として保持する。今後のPlannerでは要件確定後に、同じ粒度でA案・B案・C案の画面レイアウトを作る。

### DEV-006: `Hono`

`HonoMiniForge_Requirements.md` と `HonoMiniForge_Structure.md` の2文書。

- 目的: ノベルゲームに組み込むミニゲームを、共有APIと独立モジュールとして量産・移植する。
- 技術: Hono 4.6系、Node.js 18以上、ESM、ローカルポート3000、Vercel想定。
- 対象: `BS01` コマンドバトル、`PZL01` パズル、将来のSRPG・カードゲーム。
- 状態: 企画・構造設計段階。2026年4月の資料なので、再開時にHono、Node、Vercelの現行仕様を確認する。

## 3. Plannerへの引き継ぎルール

企画段階で要件が決まったら、次の順で作る。

1. 要件を画面・データ・操作に分解する。
2. `AppLayoutHtml` のA案・B案の粒度を基準に、A・B・Cの3レイアウト案を作る。
3. 同じ部品を異なる見せ方にする場合は、次の例を比較する。
   - Notion風DB: 表、カード、カンバン、タイムライン、ギャラリー
   - ゲームUI: 図鑑、デッキ、マップ、ステージ選択、ログ、ダッシュボード
   - 制作ツール: 左右分割、ウィザード、ノード、インスペクター、ワークスペース
4. A・B・C案の採用理由と、将来の拡張性を記録する。
