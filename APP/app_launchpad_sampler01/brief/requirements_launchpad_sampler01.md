## 1. 概要

### 名称

`app_launchpad_sampler01`

### 目的

Android と iPad で、自分の端末を Launchpad 風のドラム・サンプラーパッドとして使う。
ユーザーはジャンル別テンプレートを選択し、色付きパッドを叩いて基本ドラム音を鳴らせる。

### 初期方針

- 対象：Android を優先し、iPad でも動作する。
- 実装：React Native + TypeScript + Expo。
- 音源：アプリ同梱の WAV をパッドごとに再生する。
- 演出：フィルター・FX・ミキサーは、初期版では見た目と操作感のみを再現する。
- 範囲外：BPM同期ループ、録音、実FX、MIDI、外部アプリ連携、ユーザー音源の読み込み。

---

## 2. 利用者体験

### 基本動作

1. 起動後、テンプレートを選ぶ。
2. パッド画面を開く。
3. パッドを押すと、対応するドラム音が鳴り、押下中の色・発光が変化する。
4. 右側メニューで `パッド / フィルター / 音量 / FX` を切り替える。
5. フィルター・音量・FXでは、下部のUIが切り替わり、フェーダーやFXカードを操作できる。
6. 初期版では下部の操作は画面状態のみ更新し、音には影響しない。

### 成功条件

- テンプレートを変えると、パッド名・色・再生音が切り替わる。
- 8パッド以上を連続して叩いても、アプリが停止しない。
- 同時に複数のパッドを押したとき、各音が重なって聞こえる。
- タップ後の視覚フィードバックが即座に見える。

## 3. 機能要件

### FR-01：テンプレート選択

- 初期テンプレートは `Rock` `Jazz` `Drum & Bass` `HipHop` の4種。
- ホームまたはテンプレート選択画面から選択できる。
- 選択結果は端末に保存し、次回起動時に復元する。
- 各テンプレートはJSONデータとして管理する。

### FR-02：パッドグリッド

- 画面：横向きタブレットを基準とする。
- 配置：8列 × 6行、計48パッドを表示する。
- 初期版：各テンプレートで8〜16パッドに音源を割り当てる。残りは空パッドとして表示する。
- 表示：パッド名、色、アイコンまたは短い分類名を表示する。
- 操作：タップ／マルチタッチを受け付ける。
- 状態：`idle` `pressed` `active` `empty` を描画できる。

### FR-03：サンプル再生

- 形式：WAVを基本とする。
- 再生：パッド押下で対応WAVを再生する。
- 発音：複数パッドの同時発音を許可する。
- 読込：テンプレート選択時に必要音源を先読みする。
- 音量：初期版は各サンプルの標準音量で再生する。
- 停止：音源は末尾まで再生して終了する。ループはしない。

### FR-04：操作パネル

- 右側に `パッド` `フィルター` `音量` `FX` のモードメニューを表示する。
- 選択中モードはアクセント色で表示する。
- モードに応じてグリッド下部の領域を切り替える。

| モード | 初期版の表示 | 初期版の実音機能 |
|---|---|---|
| パッド | パッドグリッドのみ | あり |
| フィルター | 8本の縦フェーダー | なし |
| 音量 | 8本の縦フェーダー | なし |
| FX | Stutter / Flanger / Gater / Delay等のカード | なし |

### FR-05：UI状態

- フェーダーはドラッグで位置が変わる。
- FXカードはタップで選択状態・点灯状態が変わる。
- 状態はテンプレート別ではなく、現在セッションのUI状態として保持する。
- 操作状態はアプリ再起動時に保存しなくてよい。

## 4. テンプレート要件

### 共通

- 各テンプレートは最低8音を持つ。
- 音源は自作、またはアプリ内配布が許可されたライセンスのものだけを使う。
- 初期配布音源は、CC0またはアプリへの同梱・再配布を許すライセンスを記録して管理する。

### 音色セット

| ID | テンプレート | 最低音色 |
|---|---|---|
| `template_rock01` | Rock | Kick, Snare, Closed Hat, Open Hat, Crash, Tom High, Tom Low, Clap |
| `template_jazz01` | Jazz | Kick, Snare, Ride, Brush, Rim, Closed Hat, Open Hat, Tom |
| `template_dnb01` | Drum & Bass | Kick, Snare, Break, Closed Hat, Open Hat, Sub, Perc, FX |
| `template_hiphop01` | HipHop | Kick, Snare, Clap, Closed Hat, Open Hat, 808, Perc, Vocal Chop |

### JSON例

```json
{
  "id": "template_hiphop01",
  "name": "HipHop",
  "accentColor": "#ff5b2b",
  "pads": [
    {
      "id": "pad_01",
      "row": 0,
      "column": 0,
      "label": "KICK",
      "category": "drum",
      "color": "orange",
      "sample": "drum_kick_hiphop01.wav"
    }
  ]
}
```

## 5. 非機能要件

### 操作感

- タップ時の色変化は、次フレームで確認できること。
- パッドは指で押しやすい最小サイズを確保する。
- 画面遷移・モード切替は滑らかに行う。

### 対応端末

- Androidタブレット：優先。
- Androidスマートフォン：縦向きでは縮小グリッドまたはスクロール表示を許容。
- iPad：横向き表示を優先。

### データ

- テンプレート設定：JSON。
- 選択テンプレート：端末ローカル保存。
- 音源：アプリバンドルに含める。

### 品質

- オフラインで起動・再生できる。
- アカウント登録、課金、広告、サーバー通信は不要。
- クラッシュ時に選択テンプレート設定が破損しない。

## 6. 技術要件

### 採用

- UI：React Native + TypeScript
- 開発基盤：Expo
- 音声：`expo-audio` によるWAV再生
- 状態：Zustand または React Context
- 保存：AsyncStorage
- アニメーション：React Native Reanimated

### 実装上の制約

- Expo Goだけでの検証から開始してよい。
- 実FX、拍同期、低遅延最適化を追加する段階で、Expo Development BuildとSwift/Kotlinネイティブ音響モジュールへ移行する。
- 現時点ではネイティブ音響エンジンを実装しない。

---

## 7. 画面要件

### screen_home

- テンプレートカードを4枚表示する。
- テンプレート名、ジャンル色、代表音色を表示する。
- カード選択で `screen_pad` へ遷移する。

### screen_template

- テンプレート一覧と簡易プレビュー。
- 選択後は `screen_pad` へ戻る。

### screen_pad

- 上部：戻る、テンプレート名、メニュー。
- 中央：8×6パッドグリッド。
- 右側：モードメニュー。
- 下部：選択モードの操作パネル。

## 9. MVP受入条件

- [ ] Android実機で4テンプレートを選べる。
- [ ] テンプレートごとに8音以上のWAVが正しく鳴る。
- [ ] 2つ以上のパッドを同時に押しても音が重なる。
- [ ] パッド押下時に色・発光・縮小などのフィードバックがある。
- [ ] パッド／フィルター／音量／FXの画面状態を切り替えられる。
- [ ] フェーダー・FXカードが滑らかに操作できる。
- [ ] ネットワークなしで起動・演奏できる。
- [ ] テンプレート選択が次回起動後も復元される。
