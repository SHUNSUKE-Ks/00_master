# spec_return_log — 仕様差し戻しログ (app_launchpad_sampler01)

運用: 実装(Sonnet)・検証(Opus)中に仕様の曖昧さ・矛盾を見つけたら、勝手に解釈せずここへ起票して停止する。FABLEが裁定し、結果をDEVBOARDの決定事項ログへ転記する。

書式:

```
## SR-001: <一言タイトル>
- 起票: <モデル名> <日付>
- 対象: <設計書の節 / ファイル>
- 内容: <何が曖昧か。可能なら選択肢A/Bを提示>
- 裁定: （FABLE記入）
- 状態: open / closed
```
